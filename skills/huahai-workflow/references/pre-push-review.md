# 推送前代码审查（权威副本）

编码完成后、调用 `/huahai-workflow-gf` 之前执行（用户可跳过）。

按优先级：

1. **有审查 skill**（如 `/code-review`、`/review`）→ 调用该 skill
2. **无审查 skill** → 本会话自审：对照验收依据（spec/tickets 或 issue 描述），检查 diff（`git diff` / 相对 base）；有严重问题先修再审，直到无严重问题或用户确认可推。自审项（严重优先）：
   1. **验收**：是否对准验收点；有无漏改 / 误改 / 超范围
   2. **逻辑**：空值与边界、失败路径、状态/分支是否自洽
   3. **安全**：密钥、token、内网地址、PII 未进代码 / 日志 / 提交
   4. **安全**：用户输入未直接拼进 SQL / 命令 / HTML；接口变更未丢鉴权
3. **用户明确跳过审查** → 注明「用户跳过审查」后进入发布

审查通过、用户确认可推、或已跳过后，再调用 `huahai-workflow-gf`。
